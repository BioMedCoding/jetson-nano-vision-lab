Image adjustments (applied to both the display and the model input)

0

Shifts the frame's average brightness (adds a constant to every pixel). Useful in low light; too much blows out detail and can lose boxes on bright subjects.

1.00

Amplifies the difference between light and dark. Values >1 help with flat or hazy scenes; very high values saturate colours and can confuse the detector with artificial edges.

No transformation beyond brightness/contrast: the best choice for detection in normal conditions.

Detection thresholds

0.40

Minimum score below which a detection is dropped. Higher = fewer false positives but real, less certain objects may be missed; lower = more boxes, including wrong ones. 0.3–0.5 is a good starting point for these models.

0.45

Overlap above which two boxes are treated as duplicates of the same object (one is dropped by non-maximum suppression). Lower = more aggressive merging (close or overlapping objects may be lost); higher = more leftover, redundant boxes on the same object.

Runs real inference on only 1 frame in N, reusing the last detections in between. It is the one real lever for display fps on this hardware (the Jetson Nano has no DLA and no useful INT8): higher N = smoother video but detections lag behind fast objects. 1 = off.

Compression quality of the video stream to the browser only. It does not affect inference (which works on the uncompressed frame): it only reduces encoding load and bandwidth while a client is connected.

Power mode and fan

The Jetson's power mode (nvpmodel) sets the maximum CPU/GPU clocks. MAXN removes the limits (more fps, more power and heat); the 5W mode caps clocks to save energy at the cost of inference fps. Some changes need a reboot to apply fully.

Automatic follows the measured temperature: the safe choice for long runs. Manual pins the speed set below, useful for noise/temperature tests or full cooling under heavy load.

100%

Shortcut

Sets the fastest available power mode and the fan to 100% manual. It does not revert by itself: set the fan back to "Automatic" and your preferred power mode when you are done, if you want less noise and power draw.

System fan service

An independent service (automagic-fan, optional) that sets the fan from the temperature every few seconds by writing directly to the hardware. While it runs it overrides any manual value set above within 1-2 s: stop it here if you want the manual slider to stick, keep it running for thermal protection even when the dashboard is closed.
